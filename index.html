DEMO: GPU Compressed Textures with The WebXR Layers API

A demo of GPU compressed textures being used to render high quality images via the WebXR Layer API in Three.js.

This demo is mostly targeting the Meta hardware, however we can swap our "ASTC" texture format with a texture transcoded from KTX2. At that point the demo should work across devices
